## ✨ 𝗣𝗥𝗢𝗝𝗘𝗖𝗧 𝗢𝗩𝗘𝗥𝗩𝗜𝗘𝗪

This project is an interactive **Indian Premier League (IPL) Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard provides insights into IPL statistics from **2008 to 2025**, including season-wise performance, tournament winners, runners-up, batting achievements, bowling achievements, boundaries, teams, and overall match statistics.

---

## 🎯 𝗣𝗥𝗢𝗝𝗘𝗖𝗧 𝗢𝗕𝗝𝗘𝗖𝗧𝗜𝗩𝗘

The main objective of this project is to analyse historical IPL data and transform it into an interactive and visually appealing dashboard that helps users understand important trends and statistics across different IPL seasons.
